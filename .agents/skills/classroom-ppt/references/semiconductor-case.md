# 计算机视觉与半导体检测的课堂案例

这是已有课件的一个讲述范例。按本次课程、时长、受众和用户要求来选择内容。

1. 从有图案晶圆的真实划痕显微图开场，用同一处局部放大引出问题。半导体制造提供讲述的场景，计算机视觉是介绍的重点。
2. 提前展示已有研究，例如硅太阳电池图像分类、整组件图中的单电池分割、晶圆失效位置的分布识别。明确转述的是哪项研究。其中晶圆图表示测试结果的空间分布。
3. 用街景教清楚“图里有什么、在哪里、占多大范围”。把分类、目标检测、分割这些词连到可见输出。在应用页选少量案例，比如行人目标框、晶圆可疑区域、光伏电池边界。先显示实际画面，再用分步动画或短片露出标记。
4. 用几秒钟短片让听众看清原场景和输出差异。可选 YOLO 目标框、姿态关键点、真实样本的缺陷候选区。来自亮度规则的结果就标为候选区。模型输出和用于讲解的人工标记各自注明。
5. 回到实际检测，把成像、观察差异、定位候选、工位复核串起来。用同一张真实样本做前后对照。展示电致发光样本时可统一提亮供投影，保留原图和标签。以真实检测工位和工程师如何复核收尾。

选材可从实际课件使用过的来源开始。每次使用前核对原图、许可和图注。

- 有图案晶圆的光学显微图与划痕案例。[Kong 等，PWDD-Net，图 1](https://doi.org/10.3390/nano16161026)
- 真实光伏组件电致发光图和分割结果。[Deitsch 等，2021，图 1、图 9](https://doi.org/10.1007/s00138-021-01191-9)
- 单电池公开样本及其标签。[ELPV 数据集](https://github.com/zae-bayern/elpv-dataset)
- 工位、扫描电镜和探针测试现场图。[NASA Glenn 微系统制造实验室](https://www.nasa.gov/centers-and-facilities/glenn/microsystems-fabrication-laboratory/)
